# Lab4Web — Praktikum 4: CSS Layout

Proyek ini disusun berdasarkan Modul Praktikum 4: CSS Layout.

## Struktur folder
- `lab4_box.html`: latihan box element, float, dan clear.
- `lab4_layout/home.html`: halaman utama layout.
- `lab4_layout/style.css`: stylesheet eksternal untuk layout.
- `lab4_layout/artikel.html`: halaman artikel.
- `lab4_layout/about.html`: halaman About dengan deskripsi, portfolio, dan keterampilan.
- `lab4_layout/kontak.html`: halaman Contact berisi form nama, email, subjek, dan pesan.
- `screenshots/`: dokumentasi visual tahapan praktikum.
- `README.md`: panduan ini.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `Lab4Web` menggunakan VS Code.
3. Buka `lab4_box.html` di browser untuk melihat box, float, dan clear.
4. Buka `lab4_layout/home.html` di browser untuk melihat layout utama.
5. Gunakan Live Server bila tersedia; atau klik dua kali file HTML.
6. Navigasikan Home, Artikel, About, dan Kontak melalui menu.

## Tahapan praktikum
1. Membuat box element dan menerapkan `float`.
2. Menambahkan elemen keempat dengan `clear: left`.
3. Membuat kerangka layout dengan elemen semantik HTML5.
4. Menambahkan navigasi.
5. Membuat hero panel.
6. Mengatur main content dan sidebar.
7. Menambahkan widget sidebar.
8. Mengatur footer.
9. Menambahkan kartu konten dan artikel.
10. Membuat halaman About dan Contact sesuai bagian Pertanyaan dan Tugas.

## Pertanyaan dan Tugas
- About: berisi deskripsi, portfolio, dan keterampilan.
- Contact: berisi form nama, email, subjek, dan pesan.

## Screenshot
Screenshot dalam folder `screenshots` adalah visualisasi tampilan per tahap yang disusun untuk dokumentasi laporan. Untuk bukti autentik pelaksanaan di komputer sendiri, jalankan halaman di browser lalu ambil screenshot langsung dari perangkat Anda.
