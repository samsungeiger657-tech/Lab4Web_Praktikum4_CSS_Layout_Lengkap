Artikel: Mengenal CSS Layout

CSS Layout membantu menentukan posisi dan susunan elemen di dalam halaman web. Sebuah halaman umumnya terdiri dari header, navigasi, area konten, sidebar, dan footer.

Box Model

Box model tersusun atas content, padding, border, dan margin. Keempat bagian tersebut memengaruhi ukuran dan jarak suatu elemen.

Float dan Clear

Properti float dapat membuat elemen berada di sisi kiri atau kanan, sedangkan clear digunakan untuk mengatur elemen agar tidak berada di samping elemen yang mengambang.

HTML Semantik

Elemen seperti header, nav, main, section, article, aside, dan footer membantu memberi makna pada struktur dokumen.
